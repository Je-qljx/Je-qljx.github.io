## 项目简介

传统 PPT 制作工具在排版自由度、动画表现与跨平台展示上存在诸多限制。本项目提供一套基于 HTML 的演示文稿解决方案：通过图形化编辑器直接生成、编辑 HTML 幻灯片，让演示内容以网页形式呈现，兼具设计灵活性与零依赖的展示体验。

## 功能特性

- 图形化编辑界面，所见即所得地调整幻灯片布局与样式
- 直接生成标准 HTML 演示文稿，无需额外运行时即可在任意浏览器播放
- 支持常见演示元素（文本、图片、列表、代码块等）的插入与排版
- 导出为独立 HTML 文件，方便分享与离线演示

## 技术栈

- 纯 JavaScript 实现，无框架依赖，开箱即用
- 基于浏览器原生 DOM 与 CSS 完成渲染与编辑
- 单文件输出，便于分发与部署

## 使用方式

克隆仓库后在浏览器中打开编辑器页面，即可开始创建 HTML 演示文稿；编辑完成后导出 HTML 文件用于演示。
