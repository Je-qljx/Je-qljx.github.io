## 项目简介

面向合肥工业大学 2026 级新生的信息汇总页面，将入学相关的关键信息集中整理到单一网页中，帮助新生快速了解报到流程、校园生活与常用资源，减少信息分散带来的困扰。

## 功能特性

- 集中汇总新生入学所需的关键信息与常见问题
- 清晰的页面分区，按主题组织内容，便于快速查阅
- 纯静态页面，加载快、部署简单，可直接通过 GitHub Pages 访问

## 技术栈

- 纯 HTML/CSS 实现，无框架依赖
- 静态页面托管于 GitHub Pages，开箱即用

## 使用方式

直接访问在线页面即可查看全部汇总信息；如需修改内容，编辑源码后推送即可自动更新。
